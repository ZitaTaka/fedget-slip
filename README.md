# 帳票フォーム編集・保存エンジン

contentEditableで帳票フォームに記入し、HTML / Markdown / PDF でローカル(ダウンロードフォルダ)に保存するツールです。

## ファイル構成

|ファイル|用途|
|-|-|
|`report-engine.js`|本体エンジン(メニューバー表示・contentEditable化・保存処理)。他の帳票にも使い回せます|
|`style.css`|帳票の枠のスタイル(メニューバー自体のCSSはエンジンが自動で埋め込みます)|
|`sample.html`|開発用サンプル(枠を定義し、外部ファイルとして style.css / report-engine.js を読み込む形)|
|`report-form.html`|**配布用の完成品**。sample.html の内容に style.css と report-engine.js をそのまま埋め込んだ単一ファイル。これをコピーして帳票ごとに中身を書き換えて使う想定です|
|`frame-example.html`|単体の補助ツール。padding/marginゼロ・width/height 100%のiframeを表示し、`?url=` パラメータで指定したURLをそのままiframeのsrcにする。他ファイルとの依存関係は無い|
|`test/test-engine.js`|変換ロジック・保存フロー・UIのテスト(Node.js + jsdom で実行)|

## 使い方

1. `report-form.html`(または `sample.html`)をコピーして、`<div id="report-content">...</div>` の中身を自分の帳票の枠(見出し・段落・引用・表)に書き換える。
2. ブラウザで開くと、画面上部にメニューバー(保存ボタン・画像を挿入ボタン・メッセージ欄)が表示され、`#report-content` が編集可能になる。
3. 内容を記入し、Ctrl+S または「保存」ボタンを押すと保存形式(HTML/Markdown/PDF/一次保存)を選ぶダイアログが開く。選択すると、その形式でダウンロードフォルダに保存される。

   * **HTML/Markdown/PDF**: 完成品としての書き出し(HTMLはscriptタグを除去し、CSSを埋め込んだクリーンな状態)。
   * **一次保存**: 書きかけの内容を、CSS・JavaScriptも含めて今の状態のまま `wip\_(ファイル名).html` として保存する。あとでこのファイルを開けば、メニューバーや保存機能もそのまま使え、編集を再開できる。
4. 画像は「画像を挿入」ボタンでファイル選択するか、帳票エリア内にそのまま貼り付け(Ctrl+V、スクリーンショット等)すると、カーソル位置に挿入される。画像はbase64のdata URLとして埋め込まれるため、別ファイルを添付する必要はない。
5. 「ファイルを添付」ボタンでは、画像に限らず任意のファイル(PDF/Excel/Wordなど)を選択でき、「📎 ファイル名 (サイズ)」というチップとして挿入される。チップをクリックすると元のファイル名でダウンロードできる。こちらもファイル自体をdata URLとして埋め込むため、別ファイルの添付は不要。
6. 表のセル内でTabキーを押すと次のセルへ移動する。最終行の最終セルでTabを押すと新しい行が追加される(一覧表形式・単票形式どちらも同様)。一覧表形式は常に「先頭TH+残りTD」の列構成、単票形式はその行自身のTH/TDパターンを踏襲する。
7. Markdown風のショートカット・オートフォーマットに対応(詳細は下記)。
8. ブラウザタブのタイトル(`<title>`)は常に最初のH1の内容に自動で同期する。H1を編集するたびに更新され、保存ファイル名やHTML保存時の`<title>`タグにも反映される。H1が無い場合は変更されない。

## Markdown風ショートカット・オートフォーマット

選択範囲への書式:

|キー|動作|
|-|-|
|Ctrl+Shift+B|太字 ON/OFF|
|Ctrl+Shift+Y|斜体 ON/OFF|
|Ctrl+Shift+U|下線 ON/OFF|
|Ctrl+Shift+ +(プラス)|文字サイズを2pt上げる|
|Ctrl+Shift+ -(マイナス)|文字サイズを2pt下げる|
|Ctrl+Shift+K|選択中ならリンク化、未選択ならURL・表示テキストの入力フォームが開く(見出しへのページ内リンクも選択できる)|

Ctrl+Shift+Kのダイアログでは、文書内に見出しがあれば「見出しへのリンクを選択」というドロップダウンが表示され、選ぶとその見出しに自動でid(`h-1`, `h-2`...)が振られ、URL欄に`#h-1`のように入力される。`#`で始まるURL(ページ内アンカー)は新しいタブでは開かず同じページ内でジャンプする(外部URLの場合のみ新しいタブで開く)。

いずれも選択範囲が無いと動作しない(Ctrl+Shift+Kの未選択時のみ例外で、カーソル位置に新しいリンクを挿入する)。

行頭でのオートフォーマット(該当の文字列を入力した瞬間に変換される):

|入力|変換後|
|-|-|
|`# ` 〜 `###### `|H1〜H6見出し(#の数がそのままレベルになる)|
|`\* ` または `- `|箇条書き(ul)|
|`1. ` (数字+ピリオド+スペース)|番号付きリスト(ol)|
|`---` (ハイフン3つ以上)+Enter|区切り線(hr)|

箇条書き・番号付きリストの項目内では、Tabでレベルを1段下げ(ネスト)、Shift+Tabで1段上げる(ブラウザ標準のindent/outdentを利用)。

これらの書式は保存時のMarkdownにも反映される: 太字→`\*\*text\*\*`、斜体→`\*text\*`、リンク→`\[text](url)`、ネストした箇条書き→インデント付きの`-`/`1.`、区切り線→`---`。下線と文字サイズはMarkdownに対応する記法が無いため、`<u>text</u>` や `<span style="font-size:16pt">text</span>` のようにインラインHTMLとしてそのまま書き出す(多くのMarkdownビューアはこれを解釈できる)。

## 新しい帳票を作るとき

`sample.html` をベースに、`#report-content` の中身(見出し `h1`〜`h6`、段落 `p`、引用 `blockquote`、表 `table`)を自由に書き換えてください。`report-engine.js` と `style.css` は共通で使い回せます。1ファイルで配布したい場合は、`report-form.html` と同じ要領で `<link>` と `<script src>` の部分を実際のCSS/JSの中身に置き換えてください。

## Markdown変換ルール

* 見出し `h1`〜`h6` → `#`〜`######`
* 段落・通常のテキスト → そのまま
* `blockquote` → `>` 引用
* 表(`table`)は1行目の判定で2パターンに分岐します(`thead`/`tbody`の有無は問いません):

  * **1行目が全てTHの場合(一覧表形式)**: 2行目以降の各行について、行頭のTHを第1階層、各列の見出し(1行目のTH)を第2階層、対応するTDの値を第3階層としてネストした箇条書きにします。
  * **1行目にTH以外が混ざる場合(単票形式)**: 行内を先頭から走査し、THを第1階層、直後のTDを第2階層とした箇条書きにします(例: `氏名(TH)`→`山田太郎(TD)`)。
* 画像(`img`) → `!\[alt](src)`(data URLも含めそのまま埋め込み)
* 添付ファイルのチップ(`a.report-attachment`) → `\[チップの表示テキスト](href)`(data URLも含めそのまま埋め込み)

## 表の見た目・操作

* report-engine.js が表を自動判定し、`report-table-list`(一覧表形式)/`report-table-form`(単票形式)クラスを付与する。style.cssではこれを使って一覧表形式のセルを `vertical-align: top`、THの背景色を薄いグレイにしている。単票形式の見た目を変えたい場合は `table.report-table-form` に対してCSSを追加すればよい。
* 表のセル内でTabキーを押すと次のセルへ、行の最後のセルでは次の行の先頭セルへ移動する。表の最終行・最終セルでTabを押すと新しい行が追加される。

## frame-example.html について

`report-form.html` など任意のページをiframe越しに確認したい場合に使う、独立した補助ツールです。

```
frame-example.html?url=https://example.com/report-form.html
```

のように `url` パラメータへ表示したいページのURLを渡して開くと、画面全体(padding/marginゼロ、width/height 100%)にそのページがiframe表示されます。`url` を指定しない場合は、その旨のメッセージが表示されます。他のファイルには依存していないので、このファイル単体で動作します。

## 制限事項・注意点

* **PDF保存**には [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) をCDN経由(jsDelivr)で利用しています。オフライン環境ではPDF保存のみ失敗し、メッセージ欄にエラーが表示されます(HTML/Markdown保存はオフラインでも動作します)。
* 結合セル(`colspan`/`rowspan`)を含む表は変換できますが、意図通りにならない場合があるため警告メッセージを表示します。
* 画像は表(`table`)のセル内には挿入しないでください(セル内の画像はMarkdown変換時に読み飛ばされます)。本文・見出し・引用の周辺への挿入を想定しています。
* 大きな画像やファイルをそのまま添付するとdata URLが長くなり、保存ファイルのサイズが大きくなります(添付ファイルが5MBを超えるとメッセージ欄に注意が表示されます)。必要に応じて事前に圧縮・縮小してから挿入してください。
* 添付ファイルのチップ(`a.report-attachment`)は、PDF保存(html2canvasによる見た目のスクリーンショット化)では見た目のテキストのみが写り、クリックしてのダウンロードはできません。ダウンロード可能な形で残したい場合はHTML保存または一次保存を使ってください。
* HTML保存時、外部CSSファイル(`<link>`)は同一オリジンであれば内容を読み取って埋め込みますが、ブラウザのセキュリティ制限で読み取れない場合は警告を表示します。単一ファイル版(`report-form.html`)ではこの制限を受けません。
* **Ctrl+Shift+Kは要注意**: FirefoxでWebコンソール(開発者ツール)を開く操作に割り当てられた予約済みショートカットで、ページ側のJavaScriptからは上書きできません。Firefoxではリンク挿入のCtrl+Shift+Kが動作しない可能性があります。その場合は、帳票の枠側にあらかじめ`<a href="...">`を用意しておくなどの代替手段をご検討ください。
* **編集中はリンクを普通にクリックしても開きません**: `#report-content`がcontentEditableになっている間は、ブラウザの標準動作としてリンクの単純クリックはカーソル移動に使われます。リンクを実際にたどる(ページ内ジャンプ・外部サイトを開く)には Ctrl+クリック(Macは⌘+クリック)が必要です。これはブラウザ標準の仕様で、本ツール固有の制限ではありません。なお、HTML保存で書き出した完成品(contentEditableではない)を開いた場合は、通常どおり普通のクリックでリンクが機能します。
* **ページ内リンク(アンカーリンク)**: Ctrl+Shift+Kのダイアログで見出しを選ぶと自動でid(`h-1`など)が振られ、`#h-1`のようなURLが入力されます。手動で`#見出し名`のようなURLを直接入力しても、対応するidを持つ要素が文書内に無ければジャンプ先が無いため機能しません。固定表示のメニューバーで見出しが隠れないよう、ジャンプ先の要素には自動でscroll-margin-topが設定されます。
* 行頭オートフォーマット("# "や"\* "など)は、`div`/`p`/`li`/見出し/`blockquote`/表のセル(`td`/`th`)など何らかのブロック要素の中にカーソルがある場合にのみ働きます(表のセル内でも動作します)。帳票を開いて一文字も改行していない状態(要素にまだ包まれていない先頭行)では働かないことがあるため、その場合は一度Enterを押すか既存の段落内で試してください。
* 表のセル内に作った箇条書き・番号付きリストの項目内でTabを押した場合は、表の行追加ではなくリストのレベルUP(indent)が優先されます。表の行追加をしたい場合は、リストの外(セルの他の場所)にカーソルを置いてTabを押してください。
* 表のセル内に作った箇条書き・番号付きリストは、保存時のMarkdownでは(セル自体が「一覧表形式/単票形式」の箇条書きに変換される都合上)インラインHTMLとしてそのまま埋め込まれます(崩れて消えることはありません)。

## テストの実行方法

```bash
npm install jsdom
node test/test-engine.js
```

Markdown/HTML変換ロジック(太字・斜体・下線・文字サイズ・リンク・ネストした箇条書き・区切り線を含む)、警告検出、メニューバー生成、Ctrl+S/保存ボタンの動作、画像挿入(ファイル選択・貼り付け)、ファイル添付(チップ挿入・サイズ警告)、一次保存(script/CSS保持・再度開いたときの二重生成防止)、表のクラス分けとTabキーでのセル移動・行追加、書式ショートカット(Ctrl+Shift+B/Y/U・文字サイズ・リンク挿入ダイアログ、Shift無しでは発火しないことの確認含む)、リンク挿入(見出しへのページ内リンク選択・id自動付与、外部URLのみtarget=\_blankが付くことの確認含む)、タイトル同期(最初のH1の内容がdocument.title/HTML保存の<title>タグに反映されること、ファイル名用のサニタイズとは別扱いになることの確認含む)、行頭オートフォーマット(見出し・箇条書き・番号付きリスト・区切り線。表のセル内での動作とセル構造が壊れないことの確認含む)、リスト項目のTab/Shift+Tabでのレベル変更(セル内のリストでTabがindent優先になり表の行追加と競合しないことの確認含む)、保存時のダウンロード呼び出し引数などを、jsdom上で自動テストしています(77項目、実行済み・全て成功)。「編集→一次保存→再度開く」「実際のkeydownイベントでのTab/Ctrl+Shift+B/Ctrl+Shift+K/オートフォーマット操作(表のセル内含む)」というラウンドトリップの動作確認も別途行っています。PDF出力自体(html2canvasによる描画)はブラウザでの実機確認を推奨します。
